## 📝 Problem Statement

Given an integer array nums, which can have duplicate entries, provide the **power set** .

Duplicate subsets cannot exist in the solution set. Return the answer in any sequence.

### Example 1

<p>

**Input:** nums = [1, 2, 2]</p><p>

**Output:** [ [ ] , [1] , [1, 2] , [1, 2, 2] , [2] , [2, 2] ]</p>

### Example 2

<p>

**Input:** nums = [1, 2]</p><p>

**Output:** [ [ ], [1] , [2] , [1, 2] ]</p>

### Constraints

- 1 <= nums.length <= 10
- -10 <= nums[i] <= 10

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
